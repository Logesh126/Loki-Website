GITHUB GALLERY ASSET UPLOAD PACK

This package splits the 721 portfolio images into small folders, with no more than 90 files per folder (below GitHub's 100-file web upload limit). Each image has a unique filename, and gallery-data.json has been updated to point to the new folders.

UPLOAD STEPS
1. Extract this ZIP on your computer.
2. Open your GitHub repository: https://github.com/Logesh126/Loki-Website
3. Upload each folder named gallery-assets-01, gallery-assets-02, etc. to the repository root. Upload one folder per commit if needed. Keep each folder name unchanged.
4. Upload the included gallery-data.json to the repository root and replace the existing file.
5. Do not upload the ZIP itself into the repository; extract it first.
6. After all folders and gallery-data.json are in GitHub, tell ChatGPT to verify and deploy.

The original image files are preserved visually; only their filenames and folder locations are changed to avoid duplicate basename collisions.
