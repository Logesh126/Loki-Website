LOGESH PORTFOLIO — HOMEPAGE UPDATE

This update replaces only these three files in your existing project folder:
  index.html
  style.css
  app.js

It does NOT replace or delete your existing project pages, gallery-data.json, gallery-assets, or archive files.

INSTALL ON WINDOWS
1. Extract this ZIP.
2. Copy the three files from the extracted folder into your existing logesh-portfolio-complete folder.
3. Choose Replace the files when Windows asks.
4. Open PowerShell in the logesh-portfolio-complete folder.
5. Run: npx.cmd vercel --prod
6. Wait until Vercel reports the production deployment is ready.
7. Open https://logesh-creative-archive.vercel.app in a private/incognito window.

IMPORTANT
Keep the existing gallery-data.json and gallery-assets folder in the project root. The homepage reads project thumbnails and marquee images from them.
